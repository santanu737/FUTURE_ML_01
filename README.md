# FUTURE_ML_01 - Sales & Demand Forecasting for Businesses

Future Interns - Machine Learning Track | Task 1

## Overview
A forecasting model that predicts the next **90 days of sales** from 3 years of daily business data and turns the numbers into business-ready insights.

## What is inside
| File | Purpose |
|---|---|
| `sales_forecasting.ipynb` | full workflow with outputs (cleaning, features, models, evaluation, forecast) |
| `data/sales_data.csv` | daily sales data (2022-01-01 to 2024-12-31) |
| `data/generate_data.py` | script that created the dataset |
| `outputs/` | charts and `forecast_next_90_days.csv` |

## Dataset note
The dataset is **synthetic**, generated by `data/generate_data.py` to behave like retail data: upward trend, weekly and yearly seasonality, festive-season peak, plus deliberately messy rows (missing values, duplicates, outlier spikes). To use real data, replace `data/sales_data.csv` with any file that has `date` and `sales` columns and re-run the notebook.

## Approach
1. **Cleaning:** removed duplicate dates, filled missing days by interpolation, fixed outlier spikes using a rolling median.
2. **Feature engineering:** trend index, month, weekday, day of year, week, weekend flag, month-end flag, sine/cosine yearly seasonality.
3. **Models compared** on a time-based hold-out (last 90 days): Seasonal naive, Linear Regression, Trend + Random Forest, Trend + Gradient Boosting.
4. **Evaluation:** MAE, RMSE, MAPE and residual analysis by weekday.
5. **Forecast:** best model re-trained on all data, 90-day forecast with an approximate 95% range.

## Results
See the results table in the notebook (the run you see on GitHub shows the exact numbers). Charts are saved in `outputs/`.

## Key business insights
- Weekends are the strongest sales days.
- Oct-Dec is consistently above the yearly trend.
- Plan inventory with the forecast range, not only the single line.
